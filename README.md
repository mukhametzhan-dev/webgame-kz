# Дыбыстарды тап!

Қазақ тілінің дыбыстарын ажыратуға үйрететін балаларға арналған веб-ойын. Материал дисграфиядан сақтандыру сабақтарының үлгілеріне негізделген: А, Ә, Ө, Ү, І, Қ, Ғ, Ң дыбыстарына арналған 8 бөлім.

Толығымен клиент жағында жұмыс істейді (backend жоқ), прогресс `localStorage`-те сақталады. UI толығымен қазақ тілінде.

## Іске қосу

```bash
npm install
npm run dev
```

## Құрастыру

```bash
npm run build
```

## Құрылымы

- `src/data/sections.ts` — 8 бөлімнің барлық тапсырмалары (деректер моделі)
- `src/types.ts` — тапсырма түрлерінің типтері
- `src/components/tasks/` — әр тапсырма түрінің интерактивті компоненттері (дыбысты тап, орнын тап, әріпті ауыстыр, сөз құра, дыбыс сана, түспен бояу, жаттығу)
- `src/components/SectionPlayer.tsx` — бөлім ішінде тапсырмалар арасында навигация және ұпай жинау
- `src/components/ResultsScreen.tsx` — нәтиже, жұлдыздар және кері байланыс
- `src/state/useProgress.ts`, `src/state/useSound.ts` — прогресс пен дыбыс баптаулары (`localStorage`)
